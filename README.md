# 👕 متجر شياكة — أحدث صيحات الملابس الرجالي الكاجوال والتريندي
## مع لوحة تحكم وإدارة مبيعات شاملة (Full E-Commerce Admin Dashboard)

متجر إلكتروني عصري وفائق السرعة باللغة العربية (RTL) لبيع الملابس الرجالية الكاجوال (تيشيرتات أوفر سايز، هوديز شتوي، كارجو، جينز، قمصان كتان، جاكيتات بامب)، مصمم بهوية متاجر الموضة العالمية مع نظام **طلب مباشر بضغطة واحدة والدفع عند الاستلام** و**تحديد اللوكيشن GPS لخرائط جوجل**، متصل مباشرة بقاعدة بيانات **Firebase Firestore** مع **لوحة تحكم شاملة للمتجر (Admin Dashboard)**.

---

## 🌟 تفاصيل التحديث الجديد (واجهة جديدة بالكامل + Dashboard متطورة)

### ١. الواجهة الرئيسية الجديدة للمتجر ([index.html](file:///c:/Users/SHALABY%20TECH%202026/Desktop/ملابس%20رجالي/index.html)):
- **مظهر عصري ومشرق (Fresh Modern Retail Aesthetic):** تصميم أبيض ونظيف مع تباين عالي مستوحى من أشهر متاجر الموضة مثل (Zara Men / Bershka / Pull&Bear).
- **ألوان متناسقة ومريحة:** لمسات برتقالية وعنبرية أنيقة (`#F97316`) وأخضر زمردي (`#10B981`) للدفع عند الاستلام، وأزرق سيان (`#0284C7`) للـ GPS والخرائط.
- **شريط ستوري دائري تفاعلي (Story Highlights):** أيقونات سريعة في أعلى الصفحة لتصفية الأقسام (كل الكولكشن 🔥، تيشيرتات 👕، هوديز 🧥، كارجو وجينز 👖، قمصان 👔، جاكيتات 🦺).
- **طلب فوري مباشر بضغطة زر واحدة (1-Click Buy Now Modal):**
  - زر كبير على كل كارت ملابس: **"⚡ شراء فوري مباشر (الدفع عند الاستلام)"**.
  - تفتح نافذة سريعة دون مغادرة الصفحة تطلب من العميل:
    1. الاسم بالكامل.
    2. رقم الهاتف / الواتساب (تحقق تلقائي من أرقام شبكات مصر 010/011/012/015).
    3. المحافظة والعنوان بالتفصيل.
    4. **📍 اللوكيشن المحدد:** مع زر ذكي **"📍 تحديد موقعي الحالي GPS"** لالتقاط إحداثيات خريطة جوجل تلقائياً.
    5. تأكيد الدفع نقداً عند استلام ومعاينة الشحنة.
- **دوائر ألوان تفاعلية ومقاسات:** اختيار الألوان والمقاسات مباشرة على الكارت.
- **زر واتساب عائم (Floating WhatsApp Pill):** للتواصل المباشر مع خدمة العملاء في أي وقت.
- **زر تبديل المظهر (Dark / Light Mode):** يمكن للعميل أو الإدارة التبديل بين الوضع الفاتح والداكن بنقرة واحدة.

### ٢. لوحة التحكم الشاملة ([dashboard.html](file:///c:/Users/SHALABY%20TECH%202026/Desktop/ملابس%20رجالي/dashboard.html)):
لوحة تحكم إدارية متكاملة للمتجر متصلة لحظياً بـ **Firebase Firestore (`onSnapshot`)**:

#### الأقسام التفاعلية في القائمة الجانبية (Sidebar):
1. **📦 الطلبات والمبيعات (Live Orders):**
   - ٥ بطاقات لمؤشرات الأداء (إجمالي المبيعات، عدد الطلبات، طلبات قيد الانتظار، الدفع عند الاستلام، والطلبات المسلمة).
   - جدول وكروت تفاعلية بالطلبات تنزل فورياً عند طلب العميل مصحوبة بنغمة تنبيه صوتية.
   - إمكانية تغيير حالة الطلب (قيد الانتظار ⟵ تم التأكيد ⟵ جاري الشحن ⟵ تم التوصيل ⟵ ملغي) وتتحدث في فيربيز فوراً.
   - **زر واتساب وزر اتصال مباشر** لكل عميل.
   - **📍 زر "فتح اللوكيشن على خرائط جوجل (Google Maps)"** لسيارة ومندوب الشحن.
   - طباعة فواتير وبوالص الشحن الرسمية مع الباركود.
2. **📊 تحليلات المبيعات (Sales Analytics):**
   - نسب وتوزيع طرق الدفع (COD مقابل المحافظ).
   - قائمة الملابس والقطع الأكثر طلباً ومبيعاً.
3. **📍 مواقع ولوكيشن التوصيل (Delivery Locations):**
   - كروت مخصصة لكل طلب تحتوي على العنوان ورابط الـ GPS لتوجيه المناديب.
4. **👕 المخزون والمنتجات (Products Inventory):**
   - استعراض جميع ملابس المتجر المعروضة ومقاساتها وأسعارها بالجنيه المصري.
5. **👥 سجل العملاء (Customer Directory):**
   - جدول يجمع كل العملاء الذين قاموا بالطلب، أرقام هواتفهم، إجمالي طلباتهم، ومجموع ما أنفقوه، مع زر مراسلة واتساب.

### 🚀 كيفية التشغيل والتجربة:

1. افتح موجه الأوامر في مجلد المشروع وشغل السيرفر:
   ```bash
   node server.js
   ```
2. افتح الروابط في المتصفح:
   - **واجهة المتجر الرئيسية:** `http://localhost:5000/index.html`
   - **لوحة التحكم الشاملة (Dashboard):** `http://localhost:5000/dashboard.html`
   - **صفحة إتمام الطلب والـ GPS:** `http://localhost:5000/checkout.html`
