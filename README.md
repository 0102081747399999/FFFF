# 👕 متجر ملابس رجالي كاجوال وتريندي (Urban & Casual Men's Store)

متجر إلكتروني متكامل باللغة العربية (RTL) لبيع **الملابس الرجالي الكاجوال والتريندي** (تيشيرتات أوفر سايز، هوديز شتوي ميلتون، بناطيل كارجو وجينز، قمصان كاجوال كتان، وجاكيتات بامب ووتربروف)، مصمم خصيصاً لتحقيق أعلى معدل تحويل وسرعة طلب للعميل.

---

## 🚀 المميزات الرئيسية المنفذة:

### ١. طلب مباشر وسريع بأقل خطوات:
عند رغبة العميل في طلب أي قطعة ملابس، يطلب منه الموقع البيانات التالية بدقة:
1. **الاسم بالكامل**
2. **رقم الهاتف / الواتساب** (التحقق من الأرقام المصرية 010/011/012/015)
3. **المحافظة والعنوان بالتفصيل**
4. **📍 اللوكيشن الدقيق:**
   - خانة لكتابة اللوكيشن أو أقرب علامة مميزة.
   - **زر سحري ذكي: "📍 تحديد موقعي الحالي تلقائياً (GPS)"**: يلتقط إحداثيات العميل تلقائياً ويولد رابط خرائط جوجل (`Google Maps`) ليسهل على المندوب الوصول لباب البيت فوراً!
5. **طريقة الدفع: الدفع عند الاستلام (Cash on Delivery - COD)**
   - مفعلة تلقائياً كخيار أول وأساسي مع شارة تطمين: *"الدفع نقداً عند استلام ومعاينة جودة وخامة المنتج"*.
   - كما يتوفر خيار فودافون كاش لمن يفضل التحويل المسبق مع إمكانية تصوير الإيصال بالكاميرا.

---

### ٢. ضبط الألوان والتصميم العصري المبهج ("ظبطنا الألوان"):
- تم استبدال درجات البدلات القاتمة بألوان عصرية شبابية نشطة مستوحاة من أشهر متاجر الستريت وير (Zara Men / Bershka / Pull&Bear).
- خلفيات أوبسيديان عميقة ومريحة للعين (`#0B0F19` و `#111827`) مع أزرار وتفاصيل بألوان العنبر والذهب المتوهج (`#F59E0B`) وأخضر النجاح المريح (`#10B981`) للدفع عند الاستلام، وأزرق سيان (`#06B6D4`) لزر تحديد اللوكيشن.
- دوائر ألوان تفاعلية لكل قطعة ملابس لاختيار اللون المطلوب (أسود، أبيض، بيج، زيتي، كحلي، رمادي، عنابي).

### ٤. لوحة تحكم المبيعات اللحظية (`sales.html`) ⭐
الصفحة المخصصة لإدارة ومتابعة المبيعات:
- بمجرد ضغط العميل على "تأكيد الطلب"، ينزل الطلب فوراً في اللوحة مع **نغمة تنبيه صوتية**.
- يظهر لكل طلب:
  - اسم العميل ورقم هاتفه.
  - زر مباشر لمراسلة العميل على **الواتساب** بنقرة واحدة لتأكيد موعد الشحن.
  - العنوان بالتفصيل.
  - **📍 اللوكيشن**: يعرض النص الذي كتبه، مع **زر مباشر: "🗺️ فتح اللوكيشن على خرائط جوجل (Google Maps)"** ليرشد مندوب التوصيل فورياً إلى الموقع عبر GPS!
  - طريقة الدفع (الدفع عند الاستلام نقداً).
  - الملابس والمقاسات والألوان المطلوبة.
  - قائمة لتغيير حالة الطلب (قيد الانتظار ⟵ تم التأكيد ⟵ جاري التوصيل ⟵ تم التوصيل ⟵ ملغي).
  - زر طباعة فاتورة وبوليصة الشحن الرسمية.
  - زر تصدير المبيعات لملف إكسل (CSV).
  - زر **"إضافة طلب تجريبي"** لاختبار نزول الطلبات بضغطة زر.

---

### ٥. الربط بقاعدة بيانات فيربيز (Firebase Firestore):
- تم دمج إعدادات فيربيز الخاصة بمشروعك (`test-64f03`).
- تُحفظ كافة بيانات الطلب داخل مجموعة `orders`، مع نظام نسخ احتياطي محلي تلقائي (Dual Sync) ليعمل الموقع بأقصى استقرار.

---

## 🏃‍♂️ كيفية التشغيل:
افتح موجه الأوامر في مجلد المشروع واكتب:
```bash
node server.js
```
ثم توجه إلى:
- المتجر: `http://localhost:5000/index.html`
- صفحة الدفع: `http://localhost:5000/checkout.html`
- لوحة المبيعات: `http://localhost:5000/sales.html`
